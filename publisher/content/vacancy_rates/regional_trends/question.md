# Question — Regional Trends

**Written:** before EDA  
**Status:** done

---

## The Question

How have vacancy rates moved across the four Census regions since 2019?  

## The Angle

Housing supplies have been tightening, but this is not equal across all regions. We want to see how vacancy rates differ across regions, and how they have changed over time.

## Visual Hypothesis

I expect this data in a line chart format so we can see change over time. We should include the US Average and the 4 Census Regions.

## Audience

Both X and Substack.

## What Would Change the Angle

If Vacancy Rates are not different across regions.
