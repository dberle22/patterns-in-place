# Decisions

Dated records of choices that shouldn't be re-argued. Each file covers one decision: what was decided, why, and what it means in practice.

**Rules** (from [CONVENTIONS.md](../CONVENTIONS.md)):

- Name files `YYYY-MM_<slug>.md`.
- Records are append-only. To reverse a decision, write a new record that links to the old one, and add a `Superseded by` line to the old one.
- Area-specific decisions stay in that area's `decision_log` or `DECISIONS` file. This folder is for decisions that shape the whole repo or a whole product.
