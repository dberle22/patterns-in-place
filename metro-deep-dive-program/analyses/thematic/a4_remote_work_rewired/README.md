# A4 — Did Remote Work Permanently Rewire Metro Geography?

This folder will hold the national remote-work analysis and its reusable,
parameterized CBSA deep dive.

**Status:** Provisional scaffold. The ACS remote-work panel is strong; the
historical workplace-residence geography needed for the broadest version of
the question is not yet present.

Start with:

- [THEMATIC_A4_REMOTE_WORK_REWIRED_SPEC.md](THEMATIC_A4_REMOTE_WORK_REWIRED_SPEC.md)
- [THEMATIC_A4_REMOTE_WORK_REWIRED_BUILD_PLAN.md](THEMATIC_A4_REMOTE_WORK_REWIRED_BUILD_PLAN.md)
- [../THEMATIC_ANALYSES_PLAN.md](../THEMATIC_ANALYSES_PLAN.md)

The national notebook will define and test the dimensions of “rewiring” that
the available evidence supports. The market notebook will show a selected
CBSA’s WFH shift, housing response, commute context, and current employment
geography without inventing historical flows.
