# A10 — Polarization: Are Growing Sectors High-Wage or Low-Wage?

This folder will hold the national job/wage polarization analysis and its
reusable, parameterized CBSA deep dive.

**Status:** Provisional scaffold. QCEW, OEWS, QWI, and LODES provide several
useful but non-equivalent lenses; the audit must decide which one answers the
claim.

Start with:

- [THEMATIC_A10_POLARIZATION_SPEC.md](THEMATIC_A10_POLARIZATION_SPEC.md)
- [THEMATIC_A10_POLARIZATION_BUILD_PLAN.md](THEMATIC_A10_POLARIZATION_BUILD_PLAN.md)
- [../THEMATIC_ANALYSES_PLAN.md](../THEMATIC_ANALYSES_PLAN.md)

The national notebook will define whether polarization refers to job growth by
wage tier, occupational wage distributions, sector earnings, or worker-group
outcomes. The market notebook will expose the reviewed growth/wage structure
for any selected CBSA.
