# A5 — How Many Downtowns Does a Metro Have?

This folder will hold the national metro-center typology and its reusable,
parameterized CBSA deep dive.

**Status:** Provisional scaffold. Current tract employment data can support a
static national analysis; center definitions and any time claim remain open.

Start with:

- [THEMATIC_A5_HOW_MANY_DOWNTOWNS_SPEC.md](THEMATIC_A5_HOW_MANY_DOWNTOWNS_SPEC.md)

center rules. The market notebook will inspect the selected CBSA’s centers,
subcenters, housing context, and sensitivity. Editorial downtown names belong
in an issue notebook.
