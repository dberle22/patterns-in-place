# Analyses

`analyses/` holds reusable notebooks and analysis surfaces.

This includes:

- `position/` analyses such as profile, peers, and trajectory
- `explanation/` question notebooks
- `thematic/` theme notebooks
- `issue_builders/` reusable act-level builders that package standard outputs

If a notebook is parameterized and reusable across markets, it should usually
live here rather than under `issues/`.
