# exploration

Ad hoc analysis, one-off studies, and EDA that is not structured toward a publishable deep dive. This folder does not ship.

## Contents

- `national_analyses/` - cross-CBSA metric EDA, national trend work, and income studies
- `tx_school_districts/` - TX ISD lead-scoring analysis

## Usage

Add new exploratory notebooks here. If a notebook becomes structured and repeatable, promote it into `metro-deep-dive/markets/` or another product folder.
